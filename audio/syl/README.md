# Syllable recordings

1,679 Mandarin syllables in tones 1–4 (and some neutral-tone `…5` files), one MP3 per syllable,
named `<syllable><tone>.mp3` with ü written as `v` (e.g. `lv4.mp3` = lǜ). `index.json` lists them.

**Source:** [audio-cmn](https://github.com/hugolpz/audio-cmn) by Hugo Lopez (PLIDAM, INALCO),
`64k/syllabs`. **Speaker:** Chen Wang. **License:** [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/).

**Changes:** leading and trailing silence trimmed, re-encoded as mono 56 kbps MP3, `cmn-` prefix
dropped, `jv4` renamed `ju4`, the interjection files (`_hm`, `_m`, …) left out. The files in this
folder are shared under the same CC BY-SA license.
